1. Windows PC par Python 3.10+ install karo (Add to PATH tick karke) - sirf build ke liye.
2. build.bat double-click karo (2-3 min). dist folder me 2 exe milengi:
   OneDeskBiz-App.exe       -> server PC par: API Key daalo > Start Server > Open Dashboard
   OneDeskBiz-Connector.exe -> Tally PC par: Server URL + wahi API Key > Test Connection > Start Sync
Exe banne ke baad un PC par Python ki zaroorat nahi.
Tally me F1 > Settings > Connectivity > Client/Server > Server, port 9000 zaroor on rakho.
